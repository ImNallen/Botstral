# Design rubric

Score each item from zero to five.

1. Both scopes and conversation operations match the product behavior without a memory management screen.
2. Durable settlement prevents replay, overwrite, and crash windows across authoritative Markdown and SQLite.
3. Run snapshots, provenance, legacy recovery, and current protocol consumers remain coherent.
4. Secret values remain outside memory and ordinary chat, with an honest protected handoff.
5. The public model and module ownership minimize change while making bot and scope mistakes hard to express.
6. The verification plan exercises real provider tool dispatch and visible conversation outcomes.
