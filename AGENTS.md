# AGENTS.md

## Communication

- Use the fewest words that carry the full content. Cut sentences, not facts.
- Write short, complete sentences. No fragments, arrows, or abbreviations.
- Lead with the answer. No preamble, filler, pleasantries, or repeating what was already said.
- Applies to chat, commit messages, PR bodies, and review replies.

## PRs

- Merge only on an explicit request to merge, land, ship, or merge when ready. Enabling auto-merge counts as merging. A full-autopilot grant counts. The request covers only the PRs, stack, or queue it names.

## UI changes

- When a PR changes visible UI, attach before and after screenshots after the PR body sections as proof.
- Attach a video instead when the change is interactive, animated, or multi-step.
- Skip this for non-visual changes.

## Docs

- `README.md` is for humans. Keep it readable and concise.
- `AGENTS.md` is for agents. Put agent instructions here, not in `README.md`.
