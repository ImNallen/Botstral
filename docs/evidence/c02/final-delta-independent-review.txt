## Finding

### P2. Native shutdown failure skips private cleanup and evidence persistence

Location is `manager/tests/c02_browser.py`, lines 68 through 72, especially the unguarded `native.close()` at line 70. `Native.close()` in `manager/tests/c02_production.py`, lines 63 through 67, can raise when its `quit` command times out. That exception exits the browser helper's finalizer before `shutil.rmtree(local)` and `private(.../results.json, record)` run.

The retained [reproduction](c02-final-delta/probe_browser_cleanup.py) calls the actual `c02_browser.main`, `Native.close`, and `Native.call`. It substitutes local manager responses and a local protocol subprocess. The send fails after the helper writes its synthetic invitation. The failing case forces `select.select` to report timeout during quit, without waiting 150 seconds. It uses no SSH, real credentials, OS keychain, or worker.

Exact commands and results follow.

```sh
python3 .audit/c02-final-delta/probe_browser_cleanup.py --case control
```

This exits 0. The helper returns 1 for the injected send failure. The observed values are `results_exists=true`, `private_directory_exists=false`, and `invitation_exists=false`.

```sh
python3 .audit/c02-final-delta/probe_browser_cleanup.py --case cleanup-error
```

This exits 1 at `AssertionError: Cleanup failure must not discard results.json`. The actual observation is:

```json
{"case":"cleanup-error","escaped_error":"native command timed out quit","helper_return":null,"invitation_exists":true,"private_directory_exists":true,"results_exists":false}
```

The intended outcome is an unsuccessful helper result with the send and shutdown failures recorded, followed by an attempt to remove private local files even when shutdown fails. Separate the shutdown attempt, local removal, and evidence write with independent finalizers. Preserve cleanup errors instead of losing the result record. No fix was applied in this review.

Both [control](c02-final-delta/browser-cleanup-control.log) and [failure](c02-final-delta/browser-cleanup-cleanup-error.log) logs are retained. The probe removes its synthetic leftovers and reaps its local subprocess after recording observations. An initial protocol-fixture setup omitted the required `error` response field. That control failed with `'error'` before correction. Its [setup log](c02-final-delta/browser-cleanup-setup-error.log) is retained and is not a product finding.

This finding concerns future helper failure handling. It does not turn the parent's successful browser or cleanup observations into failures. I did not reproduce an OS credential leak or claim one.
